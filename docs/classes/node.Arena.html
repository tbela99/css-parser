Arena

Arena memory manager.

The node data is stored column-wise in typed arrays allocated for the capacity of the arena (getCapacity, 62 bytes per node). The arena grows by doubling its capacity and never frees memory by itself: detached nodes keep their memory and their ids stay valid. release, compact, trim and compactStrings reclaim the memory, compact() and trim() renumber the nodes. See the Arena Memory guide (files/arena.md).

find

find(node: number, matcher: AstNodeMatcher): number | null

Search the ast subtree and return the first match, in document order

// find the first declaration which name is 'aspect-ratio'
import { EnumToken, transform } from "@tbela99/css-parser";

const result = await transform(css);
const arena = result.arena;

const node = arena.find(result.ast, (arena, node) =>
    arena.getType(node) == EnumToken.DeclarationNodeType && arena.getName(node) == 'aspect-ratio');
